# 2021 Haas VF-5SS listing

## Publish on GitHub Pages

1. Extract this ZIP.
2. Upload the contents of this folder to the root of the `DavicoMFG/Haas` repository.
3. Confirm that `index.html`, `style.css`, `script.js`, and the `images` folder are all at the repository root.
4. In GitHub, open **Settings → Pages**.
5. Choose **Deploy from a branch**, select **main**, select **/(root)**, and save.
6. The site should publish at:
   `https://davicomfg.github.io/Haas/`

## Before public launch

Open `script.js` and replace:

`sales@example.com`

with the actual seller email address.

The current hero image is `images/hero.jpg`. To replace it, upload a new image using the same filename. This updates both the hero and first gallery image without editing the HTML.

## Adding gallery photos later

Add the image files to the `images` folder and copy one of the existing gallery blocks in `index.html`. Change the file name and caption.

## Price

The current price is shown as **Contact for Price**. Search `index.html` for that exact phrase when an asking price is available.
